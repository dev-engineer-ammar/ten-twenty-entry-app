## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/dev-engineer-ammar/ten-twenty-entry-app.git
cd your-folder-name
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

```bash
npm run dev
```

## Tech Stack

* Frontend: React / Vite 
* Backend: Node.js / Express
* Database: MongoDB 
* Styling: Tailwind CSS 
* API Handling: Axios / React Query

---

## Features

* User authentication (Login)
* Responsive UI
* API integration
* State management
* Error handling

## Assumptions / Notes

* Basic authentication is implemented for demo purposes
* Environment variables are required for API keys
* MongoDB connection should be configured in `.env`
